# A_iFace 6R 기구학 1단계: 회전축 구성과 정기구학

2026-11-23 설계안. **기존 3R 평면 제어에서 실제 6R 제어로 전환한 것은 아닙니다.**

## 회전 관절과 좌표계

월드 좌표계는 X=정면, Y=좌우, Z=위쪽으로 정의합니다.
모든 관절각은 라디안이며 각도 범위는 *임시 소프트웨어 가정*입니다.

| 번호 | 회전축(해당 관절의 국소 좌표) | 기능 | 임시 범위 |
|---|---|---|---|
| 1(q0) | Z | 베이스 좌우 회전 | ±170° |
| 2(q1) | Y | 어깨 상하 회전 | ±85° |
| 3(q2) | Y | 팔꿈치 상하 회전 | ±145° |
| 4(q3) | Y | 손목 상하 회전 | ±145° |
| 5(q4) | X | 화면 롤 | ±160° |
| 6(q5) | Z | 화면 말단 방향 | ±170° |

베이스 높이 0.12m, 링크 길이 0.15/0.13/0.04m는 임시 가정입니다.
손목 롤·말단 Z축은 **현재 도구 끝점에서 교차**한다고 가정합니다.
모터/브래킷/스마트폰 고정용 오프셋, 카메라 위치, 자중, 충돌 형상은 미반영입니다.

## 정기구학 (FK)

X-Y-Z 위치는 1번 베이스 회전과 2~4번 피치 관절로 계산합니다.

- r = L1 cos(q1) + L2 cos(q1+q2) + L3 cos(q1+q2+q3)
- x = r cos(q0)
- y = r sin(q0)
- z = H + L1 sin(q1) + L2 sin(q1+q2) + L3 sin(q1+q2+q3)

자세 회전행렬은 다음 순서로 계산합니다.

\`R = Rz(q0) Ry(-(q1+q2+q3)) Rx(q4) Rz(q5)\`

국소 축은 앞 관절의 회전에 따라 변합니다. 따라서 6번 로컬 Z축 회전이
모든 자세에서 월드 Z축 회전과 동일하지는 않습니다.
