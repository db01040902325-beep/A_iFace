# A_iFace 6R 3차원 기구학 설계 및 검증

2026-11-23. 기존 3R 모의제어는 보존하고, 독립적인 6R FK·IK를 구현했습니다.

## 좌표 및 축

월드 좌표는 X=정면, Y=좌우, Z=상향입니다.

| 관절 | 국소 회전축 | 역할 | 임시 소프트웨어 회전 제한 |
|---|---|---|---|
| q0 | Z | 베이스 좌우 | ±170° |
| q1 | Y | 어깨 상하 | ±85° |
| q2 | Y | 팔꿈치 상하 | ±145° |
| q3 | Y | 손목 상하 | ±145° |
| q4 | X | 말단 롤 | ±160° |
| q5 | Z | 말단 로컬 요 | ±170° |

상부 베이스 높이 0.12m, 링크 길이 0.15/0.13/0.04m는 CAD 미확정 임시값입니다.
도구 롤·요 두 축은 링크 말단의 같은 점을 통과한다고 가정하며, 실물 조립에서
오프셋이 발생하면 **FK와 IK를 모두 다시 수정**해야 합니다.

## 정기구학 (FK)

- r = L1 cos(q1) + L2 cos(q1+q2) + L3 cos(q1+q2+q3)
- x = r cos(q0), y = r sin(q0)
- z = H + L1 sin(q1) + L2 sin(q1+q2) + L3 sin(q1+q2+q3)

자세 행렬: `R = Rz(q0) Ry(-(q1+q2+q3)) Rx(q4) Rz(q5)`

로컬 관절축은 앞 관절의 회전에 따라 회전합니다.

## 역기구학 (IK)

`inverse6(position_m, rotation_matrix, cfg=Arm6Config(), current=None)`는
월드 좌표의 3차원 위치 및 3×3 회전행렬로부터 6개 관절각(라디안)을 반환합니다.

1. 목표 (x,y)에서 베이스 방위각과 180° 반전 후보를 구합니다.
2. 목표 회전행렬을 베이스 좌표계로 변환해 말단의 피치 합·롤·요를 분해합니다.
3. 손목 중심 위치를 계산하고 어깨·팔꿈치 두 가지 해를 구합니다.
4. 손목 각도·회전각 동치해 및 임시 관절 제한을 검사합니다.
5. 모든 후보를 FK로 역검산하고 현재 관절각과 가장 가까운 해를 반환합니다.

**안전한 거부 조건:** 잘못된 회전행렬, 도달 불가능한 위치, 관절 범위 초과,
베이스 축(x=y=0) 및 손목 롤 ±90° 특이점은 ValueError를 발생시킵니다.
이 경우의 일반 해, 장애물 회피, 충돌 검사 및 실제 모터 제어는 아직 미구현입니다.

## 실행

```bash
python -m aiface.arm6
python -m aiface.ik6
python -m unittest discover -s tests -v
```

자체 검산 예제는 알려진 관절각 (45°,30°,-25°,-5°,15°,20°)을 FK로 변환한
뒤 IK로 복원하고 동일한 위치·자세가 나오는지 확인합니다. 단위 테스트에는
재현 가능한 200개 무작위 유효 관절 조합이 포함되어 있습니다.

## 향후 필수 검증

- CAD 및 실제 모터·스마트폰 무게, 브래킷 오프셋을 반영한 모델 교정
- 6R 관절 속도·가속도·실시간 궤적 제어와 기계식 회전 제한
- 6R 동역학 토크 계산과 감속기 효율, 모터 정격 선정
- 카메라 고정 위치와 거리 센서의 좌표 변환 및 실제 사람과의 충돌 방지
- 물리적 E-Stop 및 모터 차단 후 더미 실험

기존 `main.py --pose-camera`는 **여전히 3R 모의 추적**이며,
6R은 현재 독립적인 기구학 검증 단계입니다.
