# 실험 계획 — 시제품 검증 기준 초안

1. 정기구학·역기구학 오차: 관절각으로 예측한 스마트폰 위치와 모형 실제 위치 오차 측정(cm).
2. 거리 제어 정확도: 표준 35/45/55 cm 거리에서 ToF 거리센서 및 실측값 MAE(mm) 비교. 현재 미구현.
3. 화면 방향 정확도: 얼굴 피치 변화 대비 거치대 각도 오차(°). 현재 미구현.
4. 응답성: 얼굴 위치 변화 이후 안정화 시간과 오버슈트, 관절 진동 빈도. 현재 미구현.
5. 동역학: 계산한 관절별 필요 토크(N·m)를 토크 정격과 비교하고 안전율 산정.
6. 안전: 얼굴 감지 실패, 센서 오류, 통신 두절, 전원 차단, 관절 제한 명령에 대한 안전정지 시험 (사람 대신 더미 사용).

results/demo.csv는 **이론 시뮬레이션 결과**이지 실제 측정 데이터가 아닙니다.
