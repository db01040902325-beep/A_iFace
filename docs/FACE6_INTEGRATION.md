# A_iFace 6R 얼굴 추종 통합 시뮬레이션

## 입력과 가정

- AI: Google MediaPipe Face Landmarker, 얼굴 수·478개 특징점·머리 Pitch/Yaw/Roll
- 깊이: 기존 눈 사이 픽셀 비율 보정으로 얻은 대략적인 거리. ToF 실측 아님
- **카메라 고정:** 베이스 위치 X=0, Y=0, Z=0.12m, 광축은 월드 +X
- 가로 영상 오프셋을 **월드 Y**라고 임시 간주. 실제 설치시 광학축 부호/외부 파라미터 교정 필요
- 세로 영상 오프셋은 월드 Z라고 임시 간주. 기본 수평 화각 60° 역시 가정
- 스마트폰 화면 자세는 q0=얼굴 측면 방위, q3=-얼굴 Pitch,
  q4=얼굴 Roll, q5=얼굴 Yaw에서 얻은 가상 회전행렬을 사용함
- 마지막 두 모터의 국소 X/Z축은 물리적 화면의 Pitch/Roll/Yaw 축과
  반드시 일치하지 않습니다. 6R IK로 근사 목표 자세에 맞추기 위한 예시입니다.

## 단계

1. 0/2명 이상 발견되면 HOLD, 1명이어도 데이터/보정 불량이면 HOLD
2. 얼굴 눈 사이 픽셀과 보정값으로 깊이를 추정, 가로/세로 좌표 투영
3. 카메라와 얼굴 사이의 수평 방향에 따라 스마트폰 거리 45cm(기본)를 유지할 위치 계산
4. 몸체 내부의 임시 목표 x≥0.06m, z=-0.05~0.46m와 기구학 제한 적용
5. 목표 3D 위치/회전행렬 → 6R IK → 6R 모의 제어
6. 상태가 HOLD면 관절 위치 고정, 복귀시 5개 연속 유효 프레임 필요
7. SPACE는 수동 정지 잠금, R 명시적으로 잠금 해제

## 시험

\`\`\`bash
python -m aiface.follow6
python -m unittest discover -s tests -v
python main.py --pose-camera6 --device 0 --pose-log6 results/face6_live.csv
\`\`\`

영상 없이 실행하는 테스트는 얼굴 좌우/위아래/앞뒤/방향 변화,
부재·다수 얼굴 HOLD, 가상 수동 정지, 추적 재개, CSV 상태를 검사합니다.

## 보류/한계

실물의 얼굴-스마트폰 안전거리, 인체 충돌, 모터 토크 및 전류, 카메라-6R
외부보정, 3차원 정확도, 물리적 E-Stop, 영상 처리 지연은 검증되지 않았습니다.
노트북에 내장된 카메라는 고정된 로봇 베이스 카메라가 아니므로 이 프로그램은
**가상 추적 시연 용도에 한정**됩니다. 실제 모터 구동에 연결하면 안 됩니다.
