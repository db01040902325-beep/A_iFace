# 구현계획서의 확정 사양과 미확정 사항

## 확정된 계획 내용
- 제목: AI 얼굴인식 기반 자동 거리 조절 스마트폰 로봇암
- 침대 머리판 고정형, 어깨·팔꿈치·손목의 3개 회전 관절
- 어깨: 스마트폰 위치, 팔꿈치: 얼굴과의 거리, 손목: 화면 방향
- Autodesk Inventor 모델링, 링크·관절 일부 3D 프린터 제작
- 카메라와 AI로 얼굴 위치·방향 인식 → 목표 위치·화면 방향 → 역기구학 → 모터 제어
- 사용자의 자세 변화 대응, 비상정지 및 관절 제한
- 얼굴 위치·방향 변화에 따른 거리·각도 조절 성능 실험

## 구현 전 별도 확정할 사항
- 링크 길이, 각 부품 무게중심 및 질량, 스마트폰 거치부 크기
- 모터 종류·관절각 범위·실제 구동 토크와 속도
- 2D 평면 구조 유지 여부(좌우 이동은 추가 축 필요)
- 카메라-로봇 좌표계 보정 및 ToF 거리센서
- 충분한 얼굴-기기 안전거리, 추락 방지·충돌 방지 하드웨어
- 라즈베리파이/ESP32 분담 및 사용자 개입 없이 시작하는 조건

## v0.1 소프트웨어의 임시 가정 (미확정)
- 링크 길이: 0.15 / 0.13 / 0.04 m
- 링크 질량: 0.10 / 0.08 / 0.04 kg
- 스마트폰 질량: 0.20 kg
- 관절 최대속도: 20°/s, 최대가속도: 80°/s²
